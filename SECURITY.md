# Seguridad

Este proyecto es un reto escolar (integración segura OT-IT). Aun así, si encuentras una falla de seguridad, avísanos de forma privada.

## Cómo reportar

Usa la pestaña **Security** del repositorio y elige **Report a vulnerability**. El reporte solo lo ven los responsables del proyecto.

Por favor no abras un issue público ni publiques la falla antes de que se corrija.

## Qué incluir

- Qué encontraste y dónde (pantalla, ruta de la API o archivo).
- Pasos para repetirlo.
- Qué impacto crees que tiene.

## Qué no incluir

Nunca pegues contraseñas, tokens ni llaves reales en el reporte.
